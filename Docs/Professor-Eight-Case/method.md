# 교수님 보고 자료 제작

- 자료 브랜치 `tooling/eight-case-professor-report`는 기존 비용 감사와 미디어 도구
  `9e8461a`를 명시적 의존성으로 사용한다. 새 AA 기법을 결합하는 연구 브랜치가 아니다.
- 기존 ①~⑥의 독립 브랜치와 ⑦/⑧ 감사 브랜치를 변경하지 않는다. 긴 캡처는 각 대응
  기준선에서 분기한 `tooling/*-long-capture`에서 harness만 수정한다. 렌더러/셰이더는 불변이다.
- 480프레임: 정지60 / 이동360 / 정지60. Fixed60, camera path time 2~8초, 기존과 같은 이동 속도.
  240프레임 클립을 반복하거나 늘린 영상이 아니다. 두 실제 장면은 Bistro와 Minecraft다.
- 기존 180-frame prefix의 RGB 동일성, 각 독립 브랜치의 ④ 전체480프레임 동일성,
  ⑦/⑧ 전체480프레임 동일성을 확인한다. PNG 저장 실행은 새 성능 측정으로 사용하지 않는다.
- 5개 확대 ROI는 원본 세 곳과 추가 두 곳이다. 이는 5개의 독립 3D 장면이라고 표현하지 않는다.
- 교수님 메일은 초안으로 작성하고 직접 발송하지 않는다. 전달 가능한 상대경로 HTML 갤러리와
  실제 GIF/MP4/WebP를 함께 묶는다. 로컬 파일 경로를 교수님에게 열리는 웹 링크처럼 쓰지 않는다.
- 성능은 기존 확정 반복 측정을 사용한다. ①②③⑤는 수정된 6-case 자료, ④⑥⑦⑧은 최신 비용 감사의
  짝 비교를 사용하며 모든 변화율의 해당 실행 ④ 분모를 명시한다. 서로 다른 실행의 절대값으로
  변화율을 다시 계산하지 않는다. 이번 번호8개는 최종 Original/Adaptive 8-case와 다르다.
- SMAA 1X stencil clear의 독립 개선과 선택적 temporal의 개선은 합산하지 않는다.
- 품질은 원본 프레임 검사 우선, CGVQM 보조. ⑧은 ⑦과 RGB가 같을 때만 기존 점수를 재사용한다.
