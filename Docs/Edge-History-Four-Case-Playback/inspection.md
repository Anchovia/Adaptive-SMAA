# 확장 비교의 원본 프레임 검사

④·⑩·⑬·⑭의 동일 frame index/pose/1920×1061 RGB PNG를 직접 열었다.
확대 sheet는 nearest 2배이며 밝기·색상 조정이나 차이 증폭이 없다.
④의 paired pattern은 On, 나머지는 Off이며 공간 SMAA는 모두 On이다.
실제 본 정지 PNG와 사용자가 재생할 GIF/MP4 제작을 구분한다.

## Bistro

- 전체 화면: 기존 ④ f130/f480과 새 비교 자료 ④·⑩·⑬·⑭ f480 원본을 직접 확인했다.
- Thin-chair `(1230,582,1358,670)`: 이동 f126–131, 후반 이동 f480–485,
  전환 f658–663, 수렴 후 정지 f700–705를 각 6개 연속 프레임으로 확인했다.
- 새 발코니 `(920,154,1080,282)`, 창살 `(950,460,1110,588)`,
  차양 `(1310,414,1470,518)`의 f130을 보완 확인했다.

의자 ROI에는 후반에도 대각선 다리와 바닥 경계가 들어온다. 방식별 가는 구조의
대비·계단과 프레임별 강약 차이가 있으며 하나의 정지 frame으로 temporal 우열을
정하지 않는다. 전환과 안정 정지는 이동 구간의 선 유지 판단과 구분한다.
검사한 정지 6프레임의 영상은 일정하며 전체 RGB hash가 마지막 변경 이후
안정적인 상태인 것과 일치한다.

## Minecraft

- 전체 화면: 기존 ④ f130/f480과 새 비교 자료 ⑩·⑬·⑭ f480 원본.
- Thin-seam `(956,524,1020,620)`: 이동 f126–131, 후반 이동 f480–485,
  전환 f658–663와 정지 f700–705를 각각 6개 연속 프레임으로 직접 확인했다.
- Leaves `(1420,590,1580,718)`: 이동 f126–131의 각 방식 원본을 6개 연속
  프레임으로 확인했다.
- 계단 `(430,510,606,686)`, 물 경계 `(1160,720,1336,848)`,
  대각 석재 `(640,326,800,454)`의 f130을 보완 확인했다.

각 ROI는 화면 고정이다. 카메라 이동 때문에 특정 경계가 ROI 밖으로 나가면 그것을
선 소실로 해석하지 않는다. 처음의 이음선과 후반의 다른 벽·잔디 경계도 구분한다.
초기 이음선의 대비는 프레임마다 달라지고, 후반 thin-seam ROI에는 처음 이음선이
아닌 다른 석재 표면이 들어온다. 나뭇잎과 잔디 경계에도 방식별 미세 대비 차이가
보이지만 이 6프레임 확인만으로 전체 반짝임 제거를 주장하지 않는다. f658–663은
이동 종료를 걸친 구간으로 ⑬·⑭의 프레임 결합 변화가 남아 있고, f700–705는
각 방식 안에서 일정한 출력이다. 이 정지 안정성은 이동 품질의 성공 판정과 구분한다.
본 확장은 확인할 구간을 늘리는 작업이며 새 absolute ghosting ground truth,
supersample reference, CGVQM 또는 성능 측정은 수행하지 않았다.

원본 경로와 전 frame RGB hash는 `*-inputs.json`, ROI/배율/확대 방식/frame 번호와
GIF·영상 재생 속도는 `*-media.json`에 있다. Gallery의 PNG는 무손실 보완 자료이고
GIF/MP4는 손실 재생용이다. 종합 품질 채택 결론은 이번 자료 생성만으로 변경하지 않는다.
