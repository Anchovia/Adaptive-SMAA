# ⑬ 원본 프레임 직접 검사

240프레임 원본 PNG를 로드해 만든 nearest 2배 sheet를 직접 열었다.
밝기·색상 보정과 차이 증폭은 사용하지 않았다. 열의 순서는 ④·⑩·⑪·⑬이다.
④의 paired sample pattern은 On, 나머지는 Off다. 공간 처리는 모두 Original SMAA다.
이 검사는 영상 재생을 직접 관찰한 기록이 아니다. GIF/MP4는 별도 확인용으로 제공한다.

- 두 장면의 전체 문맥: ④/⑬ f130, f180 원본 1920×1061 PNG.
- Bistro thin-chair `(1230,582,1358,670)`: 이동 f126–131, 전환 f178–183,
  정지 f190–195, 각 구간의 6개 연속 프레임을 직접 확인했다.
- Minecraft thin-seam `(956,524,1020,620)`: 같은 세 구간을 직접 확인했다.
- Bistro windows `(950,460,1110,588)`와 Minecraft leaves `(1420,590,1580,718)`:
  이동 f126–131 6개 연속 프레임을 추가 확인했다.

⑬의 일부 Minecraft 수직 이음선은 ⑪보다 대비가 높아져 보인다. 그러나 f126–131에서
가는 경계의 프레임별 강약과 단절이 남는다. Bilinear의 흐림을 줄이는 부분 효과와
표본 부족으로 입력부터 약해지는 구조를 분리해야 한다. 필터 교체만으로 선 소실·반짝임이
해결됐다고 판정하지 않는다.

Bistro 의자 구조도 ⑪과 전체적으로 유사하며, 가는 구조의 계단과 프레임별 변동이 남는다.
창살과 식생은 일부 더 선명해 보이지만, ④의 paired pattern과 같은 표본 안정화 효과를
얻었다고 주장할 근거는 없다. 검사한 정지 sheet의 안정성과 이동 중 품질은 별개의 판단이다.
이 구간에서 큰 분리 잔상이 새로 보였다고 단정하지는 않으며, 고스팅 해결도 입증하지 않았다.

원본 경로, ROI, frame index 및 RGB hash는 `bistro-capture.json`, `minecraft-capture.json`의
`capture_root`, `media`, `output_hashes`에 있다. 최초 sheet의 좁은 ROI 제목이 겹쳐
표시되는 문제는 생성 도구의 짧은 라벨로 수정한다. 픽셀 영역과 캡처 출력은 변경하지 않는다.

## 실제 720프레임 경로 추가 검사

두 장면의 ④/⑬ 전체 f480 원본을 열어 화면 문맥을 확인했다. 이후 긴 갤러리의
thin-chair/thin-seam nearest 2배 sheet에서 늦은 이동 f480–485, 전환 f658–663,
정지 f700–705를 각각 6개 연속 프레임씩 직접 열었다. 해당 sheet는
`C:/Users/USER/Desktop/research/Deliverables/SMAA_13_Long_20261006/`에 보존한다.
원본 경로와 각 frame RGB hash는 두 `*-long-capture.json`에 있다.

Bistro 늦은 이동의 의자 다리/대각선은 ⑪과 ⑬이 비슷하며 계단 및 픽셀 강약이 남는다.
⑬의 일부 경계가 더 선명해 보이는 것과 시간적 안정화 성공을 동일시하지 않는다.
전환 및 정지의 검사한 6프레임에서도 ⑪ 대비 큰 분리 잔상이 추가됐다고 단정할 근거는 없다.

Minecraft의 f480–485 thin-seam 고정 ROI에는 처음의 가는 이음선이 이미 화면 이동으로
들어오지 않는다. 네 방식 모두 같은 위치에서 이음선이 없는 상태이므로 이 구간을
'⑬이 선을 소실했다'거나 '선 소실을 해결했다'는 증거로 사용하지 않는다. 전환/정지에는
돌벽·잔디 경계와 굵은 어두운 면이 들어온다. 이 검사 역시 같은 가는 선의 지속 추적이 아니다.
긴 경로의 얇은 선 판정은 주로 처음 공통 구간과 전체 화면 문맥에 한정한다.

모든 GIF/MP4의 전체 프레임 decode/PTS 검증을 완료했으며 영상 재생을 직접 관찰했다고
표현하지 않는다. 실제 열어 본 원본 PNG/sheet 관찰과 확인용 영상 제작을 구분한다.
최종 품질 판단은 부분 선명도 효과가 있지만 선 소실·반짝임 해결은 미확인/미달이다.
