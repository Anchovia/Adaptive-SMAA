# ①~⑨ 속도·품질 종합 비교

2026-10-01. 사용자 지정에 따라 `F-EagerPreviousFetch`를 ⑨로 부른다. 이번 표는 검증된 기존 결과의 종합이며 새 측정이 아니다. 현재 renderer commit은 `922ee46`이다. 비교 번호 ①~⑨는 별도로 계획한 Original/Adaptive × Standard/Selective × reprojection의 최종 8-case와 구분한다.

## 구성

| 번호 | 구성 | 공간 색상 보정 | Temporal 범위 | paired jitter/subsample pattern |
|---|---|---|---|---|
| ① | AA-Off | 없음 | 없음 | Off |
| ② | SMAA 1X | 원본 SMAA | 없음 | Off |
| ③ | Temporal-only | 없음 | 전체 화면 원본 T2X-R | On |
| ④ | SMAA + 원본 T2X-R | 원본 SMAA | 전체 화면 | On |
| ⑤ | Edge temporal-only | 없음; edge 검출은 수행 | 현재 edge | Off |
| ⑥ | SMAA + 현재 edge temporal | 원본 SMAA | 현재 edge | Off |
| ⑦ | 직전 raw edge 유지·3차 depth 전달 | 원본 SMAA | 현재 + 재투영한 직전 raw edge | Off |
| ⑧ | ⑦의 1차 stencil 전달 최적화 | 원본 SMAA | ⑦과 같음 | Off |
| ⑨ | ⑧의 이전 edge 조회 순서 최적화 | 원본 SMAA | ⑦·⑧과 같음 | Off |

⑧은 현재 edge가 없을 때 이전 edge를 읽는다. ⑨는 이전 edge/velocity 조회를 앞당겨 현재 edge 판정에 종속된 분기를 제거한다. ⑨에서도 temporal 색상 읽기·결합은 선택된 union 영역에서만 실행한다. 모든 temporal 구성의 재투영은 camera/depth 기반이며 개별 물체 motion 검증 결과가 아니다. 필요한 stencil 초기화가 반영된 결과다.

## 전체 AA 시간

RTX 3060 Ti, DX11 Release x64, Ultra, 1920×1061, hidden, VSync Off, warm-up 300, 4,800프레임/반복. PNG·진단 readback·추가 세부 계측 Off. 전체 AA는 공간 처리, 필요한 준비 작업, camera velocity와 temporal resolve를 포함한다. 음수는 ④보다 시간이 짧고 양수는 길다는 뜻이다.

| ④ SMAA + 원본 T2X-R | 0.163372 | 0.00% | 0.234688 | 0.00% |
| ⑤ Edge temporal-only | 0.097097 | −38.40% | 0.117412 | −49.72% |

## Temporal resolve 시간

공간 처리와 camera velocity 생성은 제외한다. ①·②는 temporal을 실행하지 않아 이 표에서 제외했다.

각 행의 변화율은 해당 실행에 함께 측정한 ④가 분모다. 표에 표시한 최신 ④의 절대 시간을 과거 행의 공통 분모로 쓰지 않는다. ①·②·③·⑤는 기존 6회 반복, ⑦은 비용 감사 3회 반복, ④·⑥·⑧·⑨는 최신 공간 비용 실험 3회 반복 결과다. 서로 다른 실행의 절대값을 빼서 신규 개선율을 만들지 않는다.

## 품질: 기존 원본 프레임 직접 검사 결과

| 구성 | 관찰 및 한계 |
|---|---|
| ① | 공간 계단 현상과 얇은 선의 프레임별 단절이 보인다. |
| ② | 공간 경계를 완화하지만 temporal 안정화가 없어 이동 중 얇은 선 소실이 남는다. |
| ③ | 관찰한 얇은 선은 비교적 유지되지만 공간 SMAA는 적용하지 않는다. |
| ④ | 관찰한 얇은 선의 연속성이 선택적 처리보다 안정적이다. 모든 프레임에서 참조와 같은 완전한 정답은 아니다. |
| ⑤ | 선택 영역만 결합하며 공간 색상 보정이 없고 선 단절이 남는다. |
| ⑥ | 공간 SMAA는 적용되지만 이동 중 선 단절·출현 변화가 남는다. |

③·④는 Pattern On, ⑤~⑨는 Off라서 차이를 전부 edge 선택 효과로 해석하지 않는다. 점수상 Minecraft 선택적 방식이 ④보다 높아도 관찰한 선 단절·반짝임이 해결됐다는 뜻은 아니다. Global ghosting 해결도 확인되지 않았다.

## 현재 판단

- 공간 SMAA를 유지하는 temporal 구성 중 ⑥이 측정상 가장 저렴하다.
- 직전 edge를 유지하는 ⑦·⑧·⑨는 같은 출력이며, 최신 동일 실행에서 ⑨는 ⑧보다 AA 시간이 Bistro 5.16%/Minecraft 3.46% 짧다.
- ⑨는 ⑥보다 Bistro 0.71%/Minecraft 4.41% 길다. 이전 edge 유지의 비용을 없앤 것은 아니다.
- ⑨는 ④보다 Bistro 14.24% 짧고 Minecraft는 사실상 비슷하다. 관찰한 얇은 선의 구조 보존은 아직 ④ 수준에 도달하지 못했다.
